# Internationalization Guide

## Supported languages

Viewer-facing documentation is maintained in English (`en`), Japanese (`ja`), Korean (`ko`), and Thai (`th`). Every `docs/en/*.md` page must have the same filename in the other three language folders and a language switcher on its first line.

## Translate

- README files, documentation, community policies, release notes, and contribution templates.
- Headings, explanations, captions, warnings, and user instructions.
- Generated experiment-report prose through the localized report generator.

## Keep in English

Code identifiers, function and class names, filenames, paths, configuration keys, API names, workflow syntax, CLI commands, mathematical symbols, and CSV column names.

## Scientific assets

Plots and CSV data remain one canonical set so numerical evidence is identical across languages. Plot labels stay in English; localized README and figure guides provide translated captions and interpretation.

## Compatibility pages

Former `docs/*.md` URLs are multilingual language-choice pages pointing to the four localized counterparts. New links should target `docs/<language>/<filename>.md` directly.

## Validation

`python scripts/check_docs_links.py` checks every Markdown file and local image target. Multilingual tests verify file-family parity and language switchers.
