# Glossary

- **State**: variables that describe the system, here position and velocity.
- **Plant**: the physical or simulated system being controlled.
- **Control input**: the force command `u` applied to the plant.
- **Closed loop**: controller and plant connected through state feedback.
- **LQR**: Linear Quadratic Regulator, the classical baseline and teacher.
- **Equilibrium**: a state that remains unchanged; the target is the origin.
- **Lyapunov function**: positive energy-like function used to study stability.
- **Lyapunov derivative**: rate of change `V_dot` along a trajectory.
- **Actuator saturation**: a limit on achievable control input.
- **Region of attraction**: initial states that converge to an equilibrium under stated conditions.
- **Imitation learning**: training a model to reproduce teacher actions.
- **Stability-aware training**: training that includes a sampled Lyapunov penalty.
- **Ablation study**: controlled comparison that changes one design choice.

Code identifiers and mathematical symbols remain in English across all translations.
