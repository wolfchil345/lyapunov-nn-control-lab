# Portfolio Pitch

## One sentence

I built a reproducible neural-control laboratory that combines an LQR baseline, Lyapunov-aware training, robustness evaluation, automated testing, and multilingual research documentation.

## Thirty seconds

The project uses a mass-spring-damper system to train a neural network that imitates LQR. I evaluate it with closed-loop simulations, quantitative metrics, sampled Lyapunov checks, actuator limits, noise, parameter uncertainty, and estimated regions of attraction. The repository includes tests, CI, reproducible scripts, reports, and four-language documentation.

## What to show

1. Model architecture and controller-comparison figures.
2. Passing quality gate and test suite.
3. Methodology, limitations, and experiment workflow.
4. One failure mode or honest limitation.

## Keywords

`control systems`, `LQR`, `PyTorch`, `neural-network control`, `Lyapunov stability`, `robustness`, `reproducible research`
