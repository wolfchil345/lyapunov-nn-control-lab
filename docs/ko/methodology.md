# 방법론

이 문서는 Lyapunov NN Control Lab에서 사용하는 주요 제어공학 개념을 설명합니다.

## 1. 질량-스프링-댐퍼 시스템

이 프로젝트는 2차 질량-스프링-댐퍼 시스템을 대상으로 합니다.

```text
x = [위치, 속도]
```

시스템은 상태공간 형태로 표현됩니다.

```text
dx/dt = A x + B u
```

여기서 x는 상태, u는 제어 입력, A는 플랜트의 동역학, B는 입력이 플랜트에 미치는 영향을 나타냅니다.

공칭 파라미터에서 `A`의 고유값은 `-0.2 + 1.4j`와
`-0.2 - 1.4j`입니다. 두 고유값의 실수부가 모두 음수이므로 제어 입력이 없는
공칭 선형 플랜트는 이미 점근 안정합니다. LQR은 개루프 불안정 플랜트를
안정화하는 것이 아니라 과도 응답과 제어 절충을 바꿉니다. 이 프로젝트는 모방,
성능, 강건성, 안정 거동의 보존을 연구합니다.

## 2. LQR 기준 제어기

선형 이차 레귤레이터를 고전적인 최적제어 기준으로 사용합니다.

```text
u = -Kx
```

LQR은 신경망이 모방할 수 있는 강력한 기준 제어기를 제공합니다.

## 3. 신경망 제어기

신경망 제어기는 위치와 속도를 입력으로 받고 하나의 스칼라 제어 입력을 출력합니다.

```text
NN(x) ≈ LQR(x)
```

이 과정은 모방 학습이며, 신경망은 샘플링된 상태에서 LQR 제어기의 동작을 학습합니다.

## 4. Lyapunov 안정성 확인

Lyapunov 함수는 안정성을 분석하기 위해 사용하는 에너지와 유사한 함수입니다.

```text
V(x) = x^T P x
```

폐루프 동역학을 따르는 시간 미분은 다음과 같습니다.

```text
V-dot(x) = 2 x^T P (A x + B pi(x))
```

평가기는 샘플링된 상태에서 서로 다른 두 조건을 보고합니다.

```text
기본 감소 조건: V-dot(x) <= 0
감쇠 마진 조건: V-dot(x) + alpha * ||x||^2 <= 0
```

`alpha > 0`이면 두 번째 조건이 더 강합니다. 평형점에서는
`V(0) = V-dot(0) = 0`이므로 정확한 원점만 평가에서 제외하며, 원점 주변 영역은
숨기지 않습니다. 기본 수치 허용오차 `1e-9`는 부동소수점 오차를 처리하기 위한 값으로
`alpha`와 별개입니다. 격자 결과는 유한한 샘플 영역에 대한 경험적 증거이며,
연속 상태 공간 전체에 대한 형식적 안정성 인증이 아닙니다.

## 5. 안정성을 고려한 학습

신경망은 모방 손실과 Lyapunov 안정성 페널티를 함께 사용하여 학습됩니다.

```text
전체 손실 = 모방 손실 + 안정성 페널티
```

학습은 `alpha = 0.05`를 사용하며 평가와 동일한 감쇠 잔차의 양수 부분을 최소화합니다.

```text
감쇠 잔차 = V-dot(x) + alpha * ||x||^2
안정성 페널티 = mean(ReLU(감쇠 잔차))
```

## 6. 액추에이터 포화

실제 액추에이터는 무한한 힘을 발생시킬 수 없으므로 포화된 제어 입력도 실험합니다.

```text
u = clip(u, -u_max, u_max)
```

이를 통해 액추에이터 제한이 폐루프 안정성과 성능에 미치는 영향을 확인합니다.

## 7. 강건성 실험

학습된 제어기가 불완전한 조건에서도 효과적으로 동작하는지 평가합니다.

노이즈 강건성 실험에서는 측정값에 노이즈를 추가합니다.

```text
x_measured = x + noise
```

파라미터 강건성 실험에서는 질량, 감쇠, 강성을 변경하여 모델링 오차를 모의합니다.

## 8. 위상 궤적과 Lyapunov 등고선

위상 궤적은 위치와 속도를 함께 표시하여 궤적이 원점으로 이동하는지 보여줍니다.

Lyapunov 등고선 그림은 Lyapunov 함수의 레벨 집합 위에 시스템 궤적을 표시합니다.

이 그림들은 폐루프 안정성 거동을 시각적으로 설명합니다.

## 9. 유한 시간 수렴 분석

각 샘플 초기 상태 `x0`에 대해 `0 <= t <= T` 구간의 `x(t; x0)`를
시뮬레이션하고 다음의 엄격한 기준만 적용합니다.

```text
||x(T)|| < epsilon
```

평가기는 시뮬레이션이 성공하여 시각 `T`에 도달하고 시간과 상태 값이 모두
유한할 것을 요구합니다. 실패하거나 유한하지 않은 결과는 비수렴으로 조용히
분류하지 않고 오류를 발생시킵니다.

결과에는 시간 지평 `T`, 허용오차 `epsilon`, 격자 경계와 해상도, 시험 개수,
수렴 개수, 수렴 비율을 기록합니다. 이것은 샘플 유한 시간 수렴 맵입니다.
느리게 수렴하는 상태는 `t -> infinity`에서 수렴하더라도 시각 `T`의 기준을
통과하지 못할 수 있으므로, 이 실패가 수학적 끌림 영역 밖에 있음을 뜻하지 않습니다.

원점 평형점의 실제 끌림 영역은 개념적으로 다음과 같습니다.

```text
R = {x0 : x(t; x0) -> 0 as t -> infinity}.
```

유한 시간 시뮬레이션은 이 정의를 검증하지 않습니다. 방어 가능한 추정에는 감소
조건이 검증된 불변 Lyapunov 준위집합, 적용 가능한 sum-of-squares 방법,
도달성·불변성 분석, 형식 검증 또는 적절한 선형 시스템의 해석적 결과가 필요할 수
있습니다. `{x : V(x) <= c}`를 그렸다는 사실만으로 인증된 끌림 영역이 되지는
않습니다. 유한 시간 수렴 맵과 별도의 샘플 Lyapunov 검사는 서로 다른 질문에
답하며, 어느 쪽도 연속 상태 공간의 형식적 끌림 영역 인증이 아닙니다.

## 10. 안정성 가중치 어블레이션 연구

어블레이션 연구에서는 서로 다른 Lyapunov 페널티 가중치로 제어기를 학습합니다.

기본 미분 조건 위반 비율과 더 강한 감쇠 마진 조건 위반 비율을 별도로 보고하고,
최종 상태 노름, 정착 시간, 이차 비용, 제어 에너지와 함께 평가합니다.
