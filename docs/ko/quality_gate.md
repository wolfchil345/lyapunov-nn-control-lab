# 품질 검사

최종 준비 상태를 확인하려면 다음을 실행하세요.

```bash
make quality-gate
```

이 명령은 프로젝트 상태, 워크플로 배지, 환경, 결과물 목록, Markdown 링크, 전체 테스트 모음, 빠른 시작 예제를 검사합니다.

## 언제 사용하나요?

- 풀 리퀘스트를 열거나 병합하기 전.
- 추적 중인 실험 결과물을 교체하기 전.
- 데모, 제출, 릴리스 전.

## 실패했을 때

처음 실패한 명령을 확인하고 그 원인을 수정한 다음 다시 실행하세요. 실패한 단계를 건너뛰거나 변경 범위를 불필요하게 넓히지 마세요. 품질 검사 통과는 저장소의 일관성을 확인할 뿐, 구현된 테스트 범위 밖의 과학적 주장까지 검증하지는 않습니다.

GitHub Actions에서도 `.github/workflows/quality-gate.yml`을 통해 같은 명령을 실행합니다.
