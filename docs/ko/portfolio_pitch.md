# 포트폴리오 소개

## 한 문장

LQR baseline, Lyapunov-aware training, robustness evaluation, 자동 test, 다국어 연구 documentation을 결합한 재현 가능한 neural-control laboratory를 만들었습니다.

## 30초

Mass-spring-damper system에서 LQR을 모방하는 neural network를 학습합니다. Closed-loop simulation, quantitative metric, sampled Lyapunov check, actuator limit, noise, parameter uncertainty, 추정 region of attraction으로 평가합니다. Repository에는 test, CI, reproducible script, report, 4개 언어 documentation이 있습니다.

## 보여줄 것

1. Model architecture와 controller-comparison figure.
2. 통과하는 quality gate와 test suite.
3. Methodology, limitations, experiment workflow.
4. 하나의 failure mode 또는 정직한 한계.

## 키워드

`control systems`, `LQR`, `PyTorch`, `neural-network control`, `Lyapunov stability`, `robustness`, `reproducible research`
