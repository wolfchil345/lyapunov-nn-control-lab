# 포트폴리오 소개

## 한 문장 소개

LQR 기준 제어기, Lyapunov 기반 학습, 강인성 평가, 자동 테스트, 다국어 연구 문서를 결합한 재현 가능한 신경망 제어 실험실을 만들었습니다.

## 30초 소개

질량-스프링-댐퍼 시스템에서 LQR을 모방하는 신경망을 학습합니다. 폐루프 시뮬레이션, 정량 지표, 표본 기반 Lyapunov 검사, 구동기 제한, 잡음, 매개변수 불확실성, 추정 흡인 영역으로 성능을 평가합니다. 저장소에는 테스트, CI, 재현 스크립트, 보고서, 4개 언어 문서가 포함됩니다.

## 보여 줄 내용

1. 모델 구조와 제어기 비교 그림.
2. 통과한 품질 검사와 테스트 모음.
3. 방법론, 한계, 실험 절차.
4. 하나의 실패 사례나 솔직한 한계.

## 핵심어

`control systems`, `LQR`, `PyTorch`, `neural-network control`, `Lyapunov stability`, `robustness`, `reproducible research`
