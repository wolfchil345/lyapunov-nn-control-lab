# 다국어화 가이드

## 지원 언어

Viewer-facing documentation은 영어 (`en`), 일본어 (`ja`), 한국어 (`ko`), 태국어 (`th`)로 관리합니다. 모든 `docs/en/*.md` page는 다른 세 언어 folder에 같은 filename을 가져야 하며 첫 줄에 language switcher를 둡니다.

## 번역 대상

- README, documentation, community policy, release note, contribution template.
- Heading, 설명, caption, warning, user instruction.
- Localized report generator가 생성하는 experiment-report prose.

## 영어 유지 대상

Code identifier, function/class name, filename, path, configuration key, API name, workflow syntax, CLI command, 수학 기호, CSV column name.

## 과학적 asset

언어 간 수치 근거를 동일하게 하기 위해 plot과 CSV data는 하나의 canonical set을 유지합니다. Plot label은 영어로 두고 localized README와 figure guide가 번역 caption과 해석을 제공합니다.

## Compatibility page

기존 `docs/*.md` URL은 네 localized counterpart로 연결하는 다국어 language-choice page입니다. 새 link는 `docs/<language>/<filename>.md`를 직접 target으로 합니다.

## 검증

`python scripts/check_docs_links.py`는 모든 Markdown file과 local image target을 확인합니다. Multilingual test는 file-family parity와 language switcher를 검증합니다.
