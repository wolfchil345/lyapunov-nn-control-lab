# 다국어화 가이드

## 지원 언어

사용자용 문서는 영어 (`en`), 일본어 (`ja`), 한국어 (`ko`), 태국어 (`th`)로 관리합니다. 모든 `docs/en/*.md` 페이지에는 다른 세 언어 폴더에 같은 이름의 파일이 있어야 하며, 첫 줄에 언어 전환 링크를 둡니다.

## 번역 대상

- README, 문서, 커뮤니티 정책, 릴리스 노트, 기여 템플릿.
- 제목, 설명, 그림 설명문, 경고, 사용자 안내.
- 각 언어의 보고서 생성 기능이 만드는 실험 보고서 본문.

## 영어 유지 대상

코드 식별자, 함수명, 클래스명, 파일명, 경로, 설정 키, API 이름, 워크플로 구문, CLI 명령, 수학 기호, CSV 열 이름.

## 과학적 산출물

언어 간 수치 근거를 동일하게 유지하기 위해 그림과 CSV 데이터는 하나의 기준 자료를 공유합니다. 그림 안의 레이블은 영어로 유지하고, 각 언어의 README와 그림 가이드에서 번역된 설명과 해석을 제공합니다.

## 호환 페이지

기존 `docs/*.md` URL은 네 언어의 대응 페이지로 연결하는 호환 페이지로 유지합니다. 새 링크는 `docs/<language>/<filename>.md`를 직접 가리켜야 합니다.

## 검증

`python scripts/check_docs_links.py`는 모든 Markdown 파일과 로컬 이미지 대상을 확인합니다. 다국어 검사는 파일군 일관성과 언어 전환 링크를 검증합니다.
