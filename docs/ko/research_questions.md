# 연구 질문

## 주요 질문

신경망 제어기가 안정화 LQR 정책를 모방하면서 폐루프 시뮬레이션에서 유리한 표본 Lyapunov 거동과 강건성를 유지할 수 있는가?

## 성능과 안정성

- 정착 시간, 이차 비용, 제어 입력 크기가 LQR에 얼마나 가까운가?
- 표본 `V_dot`가 어디에서 음이 아니며 학습 패널티가 이를 어떻게 바꾸는가?
- 추정 흡인 영역은 LQR, 신경망 제어기, 포화 제한이 있는 신경망 제어기 사이에서 어떻게 달라지는가?

## 강건성

- 측정 잡음, 구동기 포화, 플랜트 불확실성은 수렴에 어떤 영향을 주는가?
- 어떤 테스트 사례가 먼저 실패하며 학습 영역 안인가 밖인가?

## 학습과 아키텍처

- 모방 정확도와 안정성 손실의 가중치 사이에 어떤 절충 관계가 있는가?
- KAN 제어기는 매끄러움, 해석 가능성, 강인성, 흡인 영역 결과를 어떻게 바꾸는가?

답을 보고할 때 표본점에서의 영역, 임곗값, 시드, 한계를 명시합니다.
