# References and Further Reading

หน้านี้รวมหัวข้อและเอกสารอ้างอิงที่เป็นประโยชน์สำหรับการทำความเข้าใจ Lyapunov Neural-Network Control Lab

## วิศวกรรมควบคุม

- State-space control systems
- Linear Quadratic Regulator
- Closed-loop stability
- Robust control
- Nonlinear control

## เสถียรภาพแบบ Lyapunov

- Lyapunov direct method
- Quadratic Lyapunov functions
- Lyapunov derivative conditions
- การประมาณ region-of-attraction อย่างเข้มงวดด้วย invariant Lyapunov sublevel sets, verified decrease conditions, sum-of-squares methods หรือ reachability/invariance analysis
- sampled finite-horizon convergence testing และข้อจำกัดของมัน

## Machine learning สำหรับงานควบคุม

- Neural-network controllers
- Imitation learning
- Stability-aware loss functions
- Neural Lyapunov methods
- Physics-informed learning

## การจำลองเชิงตัวเลข

- Ordinary differential equation solvers
- Grid-based evaluation
- Sensitivity to initial conditions
- Parameter variation experiments
- Measurement-noise experiments

## ตำราที่แนะนำ

- ตำรา feedback control systems สำหรับ state-space modeling และ LQR
- ตำรา nonlinear control สำหรับ Lyapunov stability และ region of attraction
- ตำรา machine learning สำหรับ neural-network training และ generalization

## แนวทางการอ่านเพิ่มเติมในอนาคต

- Learning-based control ที่มี stability guarantees
- Neural-network Lyapunov function learning
- Safe reinforcement learning สำหรับ control systems
- Formal verification ของ neural-network controllers
- Analytic attraction และ stability results สำหรับ linear systems
- Kolmogorov-Arnold Networks สำหรับ control-oriented function approximation
