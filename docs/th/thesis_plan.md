# แผนวิทยานิพนธ์

## ชื่อเบื้องต้น

การควบคุมโครงข่ายประสาทที่คำนึงถึง Lyapunov สำหรับระบบพลวัตเชิงกล

## วัตถุประสงค์

ประเมินว่าตัวควบคุมโครงข่ายประสาทที่เรียนจากตัวควบคุม LQR อ้างอิง สามารถรักษาสมรรถนะวงปิด พฤติกรรมเสถียรภาพบนจุดตัวอย่าง และความทนทานที่เหมาะสมภายใต้เงื่อนไขไม่สมบูรณ์ที่เลือกได้หรือไม่

## วิธีการ

1. กำหนดแบบจำลองปริภูมิสถานะและตัวควบคุม LQR อ้างอิง
2. ฝึกตัวควบคุมโครงข่ายประสาทด้วยค่าความสูญเสียจากการเลียนแบบและค่าความสูญเสียที่คำนึงถึงเสถียรภาพ
3. เปรียบเทียบวิถี ต้นทุน ขนาดแรงควบคุม และเวลาตั้งตัว
4. ประเมินพฤติกรรม Lyapunov บนจุดตัวอย่างและบริเวณดึงดูดโดยประมาณ
5. ทดสอบการอิ่มตัว สัญญาณรบกวน และการเปลี่ยนพารามิเตอร์
6. บันทึกข้อจำกัดและวิธีทำซ้ำผล

## โครงสร้างบทที่แนะนำ

1. บทนำและงานที่เกี่ยวข้อง
2. แบบจำลองระบบและการออกแบบ LQR
3. การฝึกตัวควบคุมโครงข่ายประสาท
4. การประเมินเสถียรภาพและความทนทาน
5. ผลลัพธ์และอภิปราย
6. ข้อจำกัด สรุป และงานอนาคต

ระบบปัจจุบันเป็นแท่นทดสอบด้วยการจำลอง การทดสอบกับฮาร์ดแวร์จริงและการพิสูจน์อย่างเป็นทางการเป็นงานต่อยอดในอนาคต
