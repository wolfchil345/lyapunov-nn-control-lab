# แผนวิทยานิพนธ์

## ชื่อเบื้องต้น

การควบคุมโครงข่ายประสาทที่คำนึงถึง Lyapunov สำหรับระบบพลวัตเชิงกล

## วัตถุประสงค์

ประเมินว่าตัวควบคุมโครงข่ายประสาทที่เรียนจากตัวควบคุม LQR อ้างอิง สามารถรักษาสมรรถนะวงปิด พฤติกรรมเสถียรภาพบนจุดตัวอย่าง และความทนทานที่มีประโยชน์ภายใต้เงื่อนไขไม่สมบูรณ์ที่เลือกได้หรือไม่

## วิธีการ

1. หา ปริภูมิสถานะ ระบบ และ LQR ตัวควบคุมอ้างอิง
2. ฝึก ตัวควบคุมโครงข่ายประสาท ด้วย การเลียนแบบ ค่าความสูญเสีย และ เสถียรภาพ-ที่คำนึงถึง ค่าความสูญเสีย
3. เปรียบเทียบ วิถี, ต้นทุน, ขนาด และ เวลาตั้งตัว
4. ประเมิน พฤติกรรม Lyapunov บนจุดตัวอย่าง และ บริเวณดึงดูด โดยประมาณ
5. ทดสอบ การอิ่มตัว, สัญญาณรบกวน และ การเปลี่ยนพารามิเตอร์
6. บันทึกข้อจำกัดและวิธีทำซ้ำผล

## โครงสร้างบทที่แนะนำ

1. บทนำและงานที่เกี่ยวข้อง
2. ระบบ แบบจำลอง และการออกแบบ LQR
3. การฝึก ตัวควบคุมโครงข่ายประสาท
4. การประเมินเสถียรภาพและ ความทนทาน
5. ผลลัพธ์และอภิปราย
6. ข้อจำกัด สรุป และงานอนาคต

ระบบปัจจุบันเป็นแท่นทดสอบด้วยการจำลอง การทดสอบกับฮาร์ดแวร์จริงและการพิสูจน์อย่างเป็นทางการเป็นงานต่อยอดในอนาคต
