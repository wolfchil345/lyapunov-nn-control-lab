# รูปและไฟล์ผลลัพธ์

| ไฟล์ | ความหมาย |
|---|---|
| `model_architecture.png` | โครงสร้างการควบคุม โครงข่ายประสาท แบบวงปิด |
| `position_comparison.png` | การตอบสนองตำแหน่งของ LQR และ ตัวควบคุมโครงข่ายประสาท |
| `training_loss.png` | ค่าความสูญเสียรวม จากการเลียนแบบ และจากเงื่อนไข Lyapunov |
| `multiple_initial_conditions.png` | การลู่เข้าของ สถานะ นอร์ม จากหลายสถานะเริ่มต้น |
| `saturation_comparison.png` | ผลของ ตัวกระตุ้น ขีดจำกัด |
| `noise_robustness.png` | การตอบสนองภายใต้ สัญญาณรบกวนการวัด |
| `parameter_robustness.png` | การตอบสนองเมื่อ ระบบ เปลี่ยน |
| `phase_portrait.png` | วิถี ในปริภูมิตำแหน่ง-ความเร็ว |
| `lyapunov_contours.png` | เส้นชั้น Lyapunov แบบกำลังสองและ วิถี |
| `region_of_attraction.png` | แผนที่การลู่เข้าจากจุดตัวอย่าง |
| `region_of_attraction_comparison.png` | เปรียบเทียบแผนที่การลู่เข้าระหว่างตัวควบคุม |
| `stability_weight_ablation.png` | ผลของน้ำหนัก เสถียรภาพ ค่าความสูญเสีย |

ข้อมูลตัวเลขอยู่ใน `performance_metrics.csv` และ `stability_weight_ablation.csv` รายงานที่สร้างขึ้นสรุปหลักฐานเดียวกัน

ข้อความใน กราฟ คงเป็นภาษาอังกฤษเพื่อให้เปรียบเทียบ เชิงวิทยาศาสตร์ สิ่งส่งมอบ ชุดเดียวกันข้ามภาษาได้ เอกสารแต่ละภาษามี คำอธิบาย และคำอธิบายที่แปลแล้ว
