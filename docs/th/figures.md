# รูปและไฟล์ผลลัพธ์

| ไฟล์ | ความหมาย |
|---|---|
| `model_architecture.png` | โครงสร้างการควบคุมวงปิดด้วยโครงข่ายประสาท |
| `position_comparison.png` | การตอบสนองตำแหน่งของ LQR และตัวควบคุมโครงข่ายประสาท |
| `training_loss.png` | ค่าความสูญเสียรวม ค่าความสูญเสียจากการเลียนแบบ และค่าความสูญเสีย Lyapunov |
| `multiple_initial_conditions.png` | การลู่เข้าของนอร์มสถานะจากหลายสถานะเริ่มต้น |
| `saturation_comparison.png` | ผลของขีดจำกัดตัวกระตุ้น |
| `noise_robustness.png` | การตอบสนองภายใต้สัญญาณรบกวนในการวัด |
| `parameter_robustness.png` | การตอบสนองเมื่อพารามิเตอร์ของระบบเปลี่ยนแปลง |
| `phase_portrait.png` | วิถีในปริภูมิตำแหน่ง-ความเร็ว |
| `lyapunov_contours.png` | เส้นชั้น Lyapunov แบบกำลังสองและวิถี |
| `region_of_attraction.png` | แผนที่การลู่เข้าจากจุดตัวอย่าง |
| `region_of_attraction_comparison.png` | เปรียบเทียบแผนที่การลู่เข้าระหว่างตัวควบคุม |
| `stability_weight_ablation.png` | ผลของน้ำหนักค่าความสูญเสียด้านเสถียรภาพ |

ข้อมูลตัวเลขอยู่ใน `performance_metrics.csv` และ `stability_weight_ablation.csv` รายงานที่สร้างขึ้นสรุปหลักฐานเดียวกัน

ข้อความในกราฟคงเป็นภาษาอังกฤษ เพื่อให้ทุกภาษาสามารถเปรียบเทียบผลลัพธ์ทางวิทยาศาสตร์ชุดเดียวกันได้ เอกสารแต่ละภาษามีคำบรรยายและคำอธิบายที่แปลแล้ว
