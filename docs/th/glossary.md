# อภิธานศัพท์

- **สถานะ:** ตัวแปรที่อธิบายระบบ ในที่นี้คือตำแหน่งและความเร็ว
- **ระบบ:** ระบบกายภาพหรือระบบจำลองที่ถูกควบคุม
- **อินพุตควบคุม:** คำสั่งแรง `u` ที่ใช้กับระบบ
- **วงปิด:** ตัวควบคุมและระบบที่เชื่อมกันด้วยการป้อนกลับสถานะ
- **LQR:** Linear Quadratic Regulator ซึ่งเป็นเกณฑ์อ้างอิงแบบดั้งเดิมและตัวควบคุมครู
- **จุดสมดุล:** สถานะที่ไม่เปลี่ยนแปลง โดยเป้าหมายคือจุดกำเนิด
- **ฟังก์ชัน Lyapunov:** ฟังก์ชันบวกที่คล้ายพลังงาน ใช้ศึกษาเสถียรภาพ
- **อนุพันธ์ Lyapunov:** อัตราการเปลี่ยนแปลง `V_dot` ตามวิถี
- **การอิ่มตัวของแอกชูเอเตอร์:** ขีดจำกัดของอินพุตควบคุมที่ทำได้
- **บริเวณดึงดูด:** ชุดของสถานะเริ่มต้นที่ลู่เข้าหาจุดสมดุลภายใต้เงื่อนไขที่ระบุ
- **การเรียนแบบเลียนแบบ:** การฝึกแบบจำลองให้ทำซ้ำการกระทำของตัวควบคุมครู
- **การฝึกที่คำนึงถึงเสถียรภาพ:** การฝึกที่รวมพจน์ปรับโทษ Lyapunov บนจุดตัวอย่าง
- **การศึกษาแบบตัดองค์ประกอบ:** การเปรียบเทียบแบบควบคุมที่เปลี่ยนตัวเลือกการออกแบบเพียงอย่างเดียว

ตัวระบุในโค้ดและสัญลักษณ์ทางคณิตศาสตร์ยังคงใช้ภาษาอังกฤษในคำแปลทุกภาษา
