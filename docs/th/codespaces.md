# การตั้งค่า GitHub Codespaces

คอนเทนเนอร์พัฒนาใช้ Python 3.12 ติดตั้งโปรเจกต์แบบแก้ไขได้พร้อม extra `dev` เปิดใช้ส่วนขยายที่แนะนำ และตั้งค่าการค้นหาชุดทดสอบของ pytest

## คำสั่งแรก

```bash
python scripts/check_environment.py
python examples/quick_start.py
make checks
```

## ขั้นตอนการพัฒนา

สร้างสาขาสำหรับงาน จำกัดขอบเขตการแก้ไขให้ชัดเจน รัน `make quality-gate` แล้วจึงคอมมิต พุช และเปิดคำขอรวมโค้ด ให้ Git ติดตามรูปที่สร้างขึ้นเฉพาะเมื่อตั้งใจเก็บเป็นผลอ้างอิง

รูปอ้างอิงที่ติดตามใช้ Git ปกติ จึงไม่ต้องใช้ Git LFS หากสภาพแวดล้อม Codespaces ไม่สอดคล้อง ให้สร้างคอนเทนเนอร์ใหม่แทนการคอมมิตไฟล์ที่สภาพแวดล้อมสร้างขึ้น
