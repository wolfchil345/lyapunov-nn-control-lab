# คำถามสำหรับการนำเสนอและสอบป้องกัน

## แรงจูงใจและการออกแบบ

**ทำไมจึงใช้ LQR?** LQR เป็นเกณฑ์อ้างอิงที่โปร่งใสและทำให้ระบบเสถียร พร้อมให้เป้าหมายการเลียนแบบที่เชื่อถือได้สำหรับระบบเชิงเส้นค่าปกติ

**โครงข่ายเรียนรู้อะไร?** เรียนรู้การแปลงจากตำแหน่งและความเร็วไปเป็นแรงควบคุมสเกลาร์

**ทำไมจึงบังคับ `u(0) = 0`?** คำสั่งที่ไม่เป็นศูนย์ที่เป้าหมายอาจทำลายจุดสมดุลที่ต้องการ

## เสถียรภาพ

**การตรวจบนกริดพิสูจน์เสถียรภาพทั่วทั้งปริภูมิหรือไม่?** ไม่ การตรวจนี้ประเมินสถานะตัวอย่างจำนวนจำกัดด้วยฟังก์ชัน Lyapunov เพียงหนึ่งตัว

**ทำไมจึงใช้ค่าปรับ Lyapunov?** ความคลาดเคลื่อนในการเลียนแบบไม่ได้วัดการลดลงของวงปิดโดยตรง ค่าปรับจึงช่วยส่งเสริมเงื่อนไขการลดลงบนจุดตัวอย่างระหว่างฝึก

## การประเมิน

**ตัวชี้วัดใดสำคัญที่สุด?** ไม่มีตัวชี้วัดเดียวที่เพียงพอ ต้องตีความการลู่เข้า ต้นทุน ความพยายามควบคุม เสถียรภาพบนจุดตัวอย่าง และความทนทานร่วมกัน

**ทำไมจึงทดสอบการอิ่มตัว สัญญาณรบกวน และการเปลี่ยนพารามิเตอร์?** ตัวควบคุมจริงมีขีดจำกัดอินพุต เซนเซอร์ที่ไม่สมบูรณ์ และความคลาดเคลื่อนของแบบจำลอง

## ข้อจำกัดและงานต่อไป

ระบบที่ใช้ยังเรียบง่าย หลักฐานทั้งหมดมาจากการจำลอง และพฤติกรรมนอกขอบเขตการฝึกยังไม่แน่นอน งานที่เข้มแข็งกว่าควรเพิ่มระบบไม่เชิงเส้น การพิสูจน์อย่างเป็นทางการ การทดลองกับฮาร์ดแวร์ หรือโครงสร้างทางเลือกเช่น KAN
