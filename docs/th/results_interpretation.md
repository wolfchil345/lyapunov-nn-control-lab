# การตีความผลลัพธ์

## ตัวชี้วัดประสิทธิภาพ

- `final_state_norm`: ระยะจากสมดุลเป้าหมายเมื่อสิ้นสุดเวลา
- `settling_time_s`: เวลาแรกที่หลังจากนั้นสถานะคงอยู่ภายในเกณฑ์
- `quadratic_cost`: อินทิกรัลของค่าลงโทษสถานะและค่าลงโทษอินพุตแบบ LQR
- `control_energy`: อินทิกรัลของอินพุตควบคุมยกกำลังสอง
- `max_abs_control`: ค่าสัมบูรณ์สูงสุดของคำสั่งควบคุม

ตัวชี้วัดเพียงค่าเดียวไม่สามารถยืนยันเสถียรภาพหรือคุณภาพของตัวควบคุมได้ ต้องพิจารณาการลู่เข้า ขนาด ต้นทุน และความทนทานร่วมกัน

## หลักฐานด้านเสถียรภาพ

ค่า `V_dot` ที่เป็นลบบนจุดตัวอย่างสนับสนุนการลดลงเฉพาะที่ภายในกริดที่ประเมิน แต่ไม่ได้พิสูจน์พฤติกรรมระหว่างจุด นอกบริเวณ หรือภายใต้ความไม่แน่นอนที่ไม่ได้ทดสอบ

## ความทนทานและบริเวณดึงดูด

สัญญาณรบกวน การเปลี่ยนพารามิเตอร์ และการอิ่มตัวของตัวกระตุ้นเป็นการทดสอบตามสถานการณ์ แผนที่บริเวณดึงดูดจำแนกเฉพาะสถานะเริ่มต้นที่สุ่มตัวอย่าง ภายใต้ช่วงเวลาประเมินและเกณฑ์ที่เลือก

## ลำดับการอ่าน

1. ตรวจการตั้งค่าและค่าเมล็ดสุ่ม
2. ตรวจวิถีและขีดจำกัดของอินพุตควบคุม
3. เปรียบเทียบตัวชี้วัดเชิงปริมาณ
4. ตรวจผลวิเคราะห์ Lyapunov และบริเวณดึงดูด
5. อ่าน [ข้อจำกัด](limitations.md) และบันทึกกรณีล้มเหลว
