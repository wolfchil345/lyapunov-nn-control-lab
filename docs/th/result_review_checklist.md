# รายการตรวจทบทวนผลลัพธ์

## ค่าตั้ง

- [ ] บันทึกบรานช์ คอมมิต ค่าเมล็ดสุ่ม จำนวนรอบฝึก และโครงสร้างโมเดล
- [ ] บันทึกเงื่อนไขเริ่มต้น ระยะเวลา ความหนาแน่นกริด สัญญาณรบกวน และกรณีพารามิเตอร์
- [ ] การรันที่นำมาเปรียบเทียบแตกต่างกันเฉพาะตัวแปรที่ตั้งใจเปลี่ยน

## ผลลัพธ์

- [ ] มีไฟล์ CSV รายงาน โมเดล และรูปตามที่คาดหวัง
- [ ] ป้ายในรูปอ่านได้ง่าย และวิถีมีความสมเหตุสมผล
- [ ] ตัวชี้วัดมีค่าจำกัดและถูกตีความร่วมกัน
- [ ] ระบุกรณีการอิ่มตัว สัญญาณรบกวน และพารามิเตอร์อย่างชัดเจน

## ข้อสรุปเรื่องเสถียรภาพ

- [ ] อธิบายการตรวจ Lyapunov บนจุดตัวอย่างว่าเป็นหลักฐานเชิงประจักษ์
- [ ] ข้อสรุปเรื่องบริเวณดึงดูดระบุกริด ช่วงเวลาประเมิน และเกณฑ์ที่ใช้
- [ ] เก็บและอธิบายกรณีล้มเหลวกับพฤติกรรมที่ไม่คาดคิด

## ก่อนคอมมิต

- [ ] `make quality-gate` ผ่าน
- [ ] `git diff` มีเฉพาะผลลัพธ์ที่ตั้งใจเปลี่ยน
- [ ] เอกสารและบันทึกการทดลองตรงกับผลที่สร้างขึ้น
