# การอัปเดตแพ็กเกจที่ต้องใช้

Dependabot ตรวจแพ็กเกจ Python และ GitHub Actions ตามตารางที่กำหนด

## รายการตรวจสอบสำหรับการทบทวน

1. อ่านบันทึกรีลีสจากโครงการต้นทาง และตรวจหาการเปลี่ยนแปลงที่ทำลายความเข้ากันได้
2. อัปเดตไลบรารีที่เกี่ยวข้องกันครั้งละหนึ่งกลุ่ม
3. รัน `python -m pip check`, `make checks` และ `make quality-gate`
4. สร้างผลการทดลองใหม่เฉพาะเมื่อแพ็กเกจที่เปลี่ยนอาจกระทบค่าตัวเลขหรือกราฟ
5. ตรวจผลลัพธ์ที่เปลี่ยนทั้งหมดและบันทึกความต่างเชิงตัวเลขที่มีความหมาย

อย่ารวมโค้ดเพียงเพราะ CI ผ่าน ต้องยืนยันด้วยว่าพฤติกรรมการควบคุมและผลที่บันทึกไว้ยังน่าเชื่อถือ
