# ระเบียบวิธี

เอกสารนี้อธิบายแนวคิดหลักด้านวิศวกรรมควบคุมที่ใช้ใน Lyapunov NN Control Lab

## 1. ระบบมวล-สปริง-แดมเปอร์

โปรเจกต์นี้ศึกษาระบบมวล-สปริง-แดมเปอร์อันดับสอง

```text
x = [ตำแหน่ง, ความเร็ว]
```

ระบบเขียนในรูปแบบปริภูมิสถานะได้ดังนี้

```text
dx/dt = A x + B u
```

โดย x คือสถานะ u คืออินพุตควบคุม A อธิบายพลวัตของระบบ และ B อธิบายผลของอินพุตที่มีต่อระบบ

สำหรับพารามิเตอร์ nominal ค่า eigenvalue ของ `A` คือ `-0.2 + 1.4j` และ
`-0.2 - 1.4j` ซึ่งมีส่วนจริงเป็นลบทั้งคู่ ดังนั้นระบบเชิงเส้น nominal ที่ไม่มี
อินพุตควบคุมจึงมีเสถียรภาพแบบ asymptotic อยู่แล้ว LQR เปลี่ยนการตอบสนองชั่วคราว
และ trade-off ของการควบคุม ไม่ได้ทำให้ระบบ nominal ที่ไม่เสถียรกลายเป็นเสถียร
โปรเจกต์นี้จึงศึกษาการเลียนแบบ สมรรถนะ ความทนทาน และการรักษาพฤติกรรมที่เสถียร

## 2. ตัวควบคุมพื้นฐาน LQR

ใช้ Linear Quadratic Regulator เป็นตัวควบคุมอ้างอิงของการควบคุมเหมาะที่สุดแบบดั้งเดิม

```text
u = -Kx
```

LQR เป็นตัวควบคุมอ้างอิงที่มีประสิทธิภาพสำหรับให้ neural network เรียนรู้และเลียนแบบ

## 3. ตัวควบคุมโครงข่ายประสาทเทียม

ตัวควบคุม neural network รับตำแหน่งและความเร็วเป็นอินพุต และส่งออกอินพุตควบคุมแบบสเกลาร์หนึ่งค่า

```text
NN(x) ≈ LQR(x)
```

กระบวนการนี้คือ imitation learning โดย neural network เรียนรู้พฤติกรรมของ LQR controller จากสถานะที่สุ่มตัวอย่าง

## 4. การตรวจสอบเสถียรภาพแบบ Lyapunov

ฟังก์ชัน Lyapunov เป็นฟังก์ชันที่คล้ายพลังงานและใช้ในการวิเคราะห์เสถียรภาพ

```text
V(x) = x^T P x
```

อนุพันธ์ตามพลวัตวงปิดคำนวณได้ดังนี้

```text
V-dot(x) = 2 x^T P (A x + B pi(x))
```

ตัวประเมินรายงานเงื่อนไขที่แตกต่างกันสองแบบบนสถานะที่สุ่มตัวอย่าง

```text
เงื่อนไขการลดลงพื้นฐาน: V-dot(x) <= 0
เงื่อนไข decay margin:  V-dot(x) + alpha * ||x||^2 <= 0
```

เงื่อนไขที่สองเข้มงวดกว่าเมื่อ `alpha > 0` ที่จุดสมดุลมี
`V(0) = V-dot(0) = 0` จึงตัดออกเฉพาะจุดกำเนิดที่แน่นอนโดยไม่ซ่อนบริเวณรอบจุดกำเนิด
ค่าความคลาดเคลื่อนเชิงตัวเลขเริ่มต้น `1e-9` ใช้สำหรับจัดการข้อผิดพลาด floating-point และแยกจาก
`alpha` ผลจากกริดเป็นหลักฐานเชิงประจักษ์บนบริเวณตัวอย่างที่มีขอบเขตจำกัดเท่านั้น
ไม่ใช่ใบรับรองเสถียรภาพอย่างเป็นทางการสำหรับปริภูมิสถานะต่อเนื่องทั้งหมด

## 5. การฝึกที่คำนึงถึงเสถียรภาพ

neural network ถูกฝึกด้วยทั้ง imitation loss และ Lyapunov stability penalty

```text
total loss = imitation loss + stability penalty
```

การฝึกใช้ `alpha = 0.05` และลดส่วนที่เป็นบวกของ decay residual เดียวกับที่ใช้ในการประเมิน

```text
decay residual = V-dot(x) + alpha * ||x||^2
stability penalty = mean(ReLU(decay residual))
```

## 6. การอิ่มตัวของแอคชูเอเตอร์

แอคชูเอเตอร์จริงไม่สามารถสร้างแรงได้อย่างไม่จำกัด จึงมีการทดสอบอินพุตควบคุมแบบอิ่มตัวด้วย

```text
u = clip(u, -u_max, u_max)
```

การทดลองนี้แสดงผลของขีดจำกัดแอคชูเอเตอร์ต่อเสถียรภาพและสมรรถนะของระบบวงปิด

## 7. การทดลองความทนทาน

โปรเจกต์ประเมินว่าตัวควบคุมที่เรียนรู้แล้วยังคงทำงานได้ดีภายใต้สภาวะที่ไม่สมบูรณ์หรือไม่

การทดลองความทนทานต่อสัญญาณรบกวนจะเพิ่ม noise ให้กับค่าที่วัดได้

```text
x_measured = x + noise
```

การทดลองความทนทานต่อพารามิเตอร์จะเปลี่ยนมวล ค่าหน่วง และค่าความแข็งของสปริง เพื่อจำลองความคลาดเคลื่อนของแบบจำลอง

## 8. แผนภาพเฟสและเส้นชั้นของ Lyapunov

แผนภาพเฟสพล็อตตำแหน่งเทียบกับความเร็ว และแสดงว่าวิถีเคลื่อนเข้าสู่จุดกำเนิดหรือไม่

กราฟเส้นชั้น Lyapunov แสดงวิถีของระบบทับบนระดับค่าของฟังก์ชัน Lyapunov

กราฟเหล่านี้ช่วยอธิบายพฤติกรรมเสถียรภาพของระบบวงปิดด้วยภาพ

## 9. การวิเคราะห์การลู่เข้าในช่วงเวลาจำกัด

สำหรับสถานะเริ่มต้นตัวอย่างแต่ละค่า `x0` การทดลองจำลอง `x(t; x0)` ในช่วง
`0 <= t <= T` และใช้เกณฑ์แบบเข้มงวดเพียงเกณฑ์ต่อไปนี้

```text
||x(T)|| < epsilon
```

ตัวประเมินกำหนดให้การจำลองสำเร็จ ไปถึงเวลา `T` และให้ค่าเวลาและสถานะที่เป็น finite
หากการจำลองล้มเหลวหรือให้ค่าที่ไม่เป็น finite จะเกิดข้อผิดพลาดแทนการจัดประเภทเป็นไม่ลู่เข้า

ผลลัพธ์บันทึกช่วงเวลา `T`, ค่าความคลาดเคลื่อน `epsilon`, ขอบเขตและความละเอียด
ของกริด จำนวนที่ทดสอบ จำนวนที่ลู่เข้า และสัดส่วนการลู่เข้า นี่คือแผนที่การลู่เข้า
ในช่วงเวลาจำกัดจากตัวอย่าง สถานะที่ลู่เข้าช้าอาจไม่ผ่านเกณฑ์ที่เวลา `T` แม้จะลู่เข้า
เมื่อ `t -> infinity` ดังนั้นความล้มเหลวนี้ไม่ได้หมายความว่าสถานะอยู่นอกบริเวณดึงดูด
ทางคณิตศาสตร์

บริเวณดึงดูดที่แท้จริงของจุดสมดุลที่จุดกำเนิดนิยามในเชิงแนวคิดว่า

```text
R = {x0 : x(t; x0) -> 0 as t -> infinity}.
```

การจำลองแบบจำกัดเวลาไม่ยืนยันนิยามนี้ การประมาณที่มีเหตุผลรองรับอาจต้องใช้
Lyapunov sublevel set ที่เป็น invariant และตรวจสอบเงื่อนไขการลดลงแล้ว วิธี
sum-of-squares ที่เหมาะสม การวิเคราะห์ reachability/invariance การตรวจสอบแบบ formal
หรือผลเชิงวิเคราะห์สำหรับระบบเชิงเส้นที่เหมาะสม การวาด `{x : V(x) <= c}` เพียงอย่างเดียว
ไม่ได้ทำให้เป็นบริเวณดึงดูดที่รับรองแล้ว แผนที่การลู่เข้าในช่วงเวลาจำกัดและการตรวจสอบ
Lyapunov จากตัวอย่างตอบคำถามต่างกัน และทั้งสองอย่างไม่ใช่ใบรับรองบริเวณดึงดูด
อย่างเป็นทางการบนปริภูมิสถานะต่อเนื่อง

## 10. การศึกษา ablation ของค่าน้ำหนักเสถียรภาพ

การศึกษา ablation ฝึกตัวควบคุมด้วยค่าน้ำหนัก Lyapunov penalty ที่แตกต่างกัน

การทดลองรายงานสัดส่วนการละเมิดเงื่อนไขอนุพันธ์พื้นฐานและเงื่อนไข decay margin
ที่เข้มงวดกว่าแยกจากกัน พร้อมกับ final state norm, settling time, quadratic cost และ control energy

## 11. สรุป

โปรเจกต์นี้ผสมผสานการควบคุมแบบดั้งเดิม การเรียนรู้แบบเลียนแบบด้วย neural network
การวิเคราะห์ Lyapunov การทดสอบความทนทาน และการวิเคราะห์การลู่เข้าในช่วงเวลาจำกัดจากตัวอย่าง

