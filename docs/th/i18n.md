# คู่มือการทำหลายภาษา

## ภาษาที่รองรับ

เอกสารสำหรับผู้ใช้ได้รับการดูแลเป็นภาษาอังกฤษ (`en`) ญี่ปุ่น (`ja`) เกาหลี (`ko`) และไทย (`th`) ทุกหน้าใน `docs/en/*.md` ต้องมีไฟล์ชื่อเดียวกันในโฟลเดอร์อีกสามภาษา และมีลิงก์สลับภาษาในบรรทัดแรก

## สิ่งที่แปล

- README เอกสาร นโยบายชุมชน บันทึกประจำรุ่น และแม่แบบการมีส่วนร่วม
- หัวข้อ คำอธิบาย คำบรรยายรูป คำเตือน และคำแนะนำสำหรับผู้ใช้
- เนื้อหารายงานการทดลองที่สร้างโดยระบบรายงานหลายภาษา

## สิ่งที่คงเป็นภาษาอังกฤษ

ตัวระบุในโค้ด ชื่อฟังก์ชัน ชื่อคลาส ชื่อไฟล์ พาธ คีย์การตั้งค่า ชื่อ API ไวยากรณ์เวิร์กโฟลว์ คำสั่ง CLI สัญลักษณ์คณิตศาสตร์ และชื่อคอลัมน์ CSV

## สิ่งส่งมอบทางวิทยาศาสตร์

กราฟและข้อมูล CSV ใช้ชุดอ้างอิงเดียวกันเพื่อให้หลักฐานเชิงตัวเลขตรงกันทุกภาษา ป้ายกำกับภายในกราฟคงเป็นภาษาอังกฤษ ส่วน README และคู่มือรูปในแต่ละภาษาให้คำอธิบายและการตีความที่แปลแล้ว

## หน้าเข้ากันได้กับลิงก์เดิม

URL เดิมใน `docs/*.md` ยังคงเป็นหน้าที่นำไปยังเอกสารทั้งสี่ภาษา ส่วนลิงก์ใหม่ควรชี้ตรงไปที่ `docs/<language>/<filename>.md`

## การตรวจสอบ

`python scripts/check_docs_links.py` ตรวจไฟล์ Markdown ทั้งหมดและปลายทางรูปภายใน ส่วนการตรวจหลายภาษาตรวจความครบถ้วนของชุดไฟล์และลิงก์สลับภาษา
