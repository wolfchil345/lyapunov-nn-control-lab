# คู่มือการทำหลายภาษา

## ภาษาที่รองรับ

Viewer-facing documentation ดูแลเป็นอังกฤษ (`en`), ญี่ปุ่น (`ja`), เกาหลี (`ko`) และไทย (`th`) ทุก `docs/en/*.md` page ต้องมี filename เดียวกันใน folder อีกสามภาษาและมี language switcher ในบรรทัดแรก

## สิ่งที่แปล

- README, documentation, community policy, release note และ contribution template
- Heading, explanation, caption, warning และ user instruction
- Prose ของ experiment report ที่สร้างผ่าน localized report generator

## สิ่งที่คงเป็นภาษาอังกฤษ

Code identifier, function/class name, filename, path, configuration key, API name, workflow syntax, CLI command, สัญลักษณ์คณิตศาสตร์ และ CSV column name

## Scientific asset

Plot และ CSV data ใช้ canonical set เดียวเพื่อให้หลักฐานตัวเลขเหมือนกันทุกภาษา Plot label คงเป็นภาษาอังกฤษ ส่วน localized README และ figure guide ให้ caption กับการตีความที่แปลแล้ว

## Compatibility page

URL เดิม `docs/*.md` เป็น multilingual language-choice page ที่ชี้ไป counterpart ทั้งสี่ภาษา Link ใหม่ควร target `docs/<language>/<filename>.md` โดยตรง

## การตรวจสอบ

`python scripts/check_docs_links.py` ตรวจ Markdown file ทั้งหมดและ local image target ส่วน multilingual test ตรวจ file-family parity และ language switcher
