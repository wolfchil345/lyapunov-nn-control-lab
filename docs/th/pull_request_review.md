# การทบทวนคำขอรวมโค้ด

## การทบทวนทั่วไป

- [ ] ชื่อเรื่องและสรุปอธิบายการเปลี่ยนแปลงที่มีจุดประสงค์เดียว
- [ ] การทดสอบและการตรวจที่บังคับผ่านทั้งหมด
- [ ] อัปเดตเอกสารทั้งสี่ภาษาเมื่อพฤติกรรมที่ผู้ใช้เห็นเปลี่ยนไป
- [ ] กำหนดอย่างตั้งใจว่าจะเก็บหรือละเว้นไฟล์ที่สร้างขึ้น
- [ ] แก้ไขบทสนทนาทั้งหมดก่อนรวมโค้ด

## การทบทวนด้านวิทยาศาสตร์

- [ ] ระบุการเปลี่ยนค่าเมล็ดสุ่ม พารามิเตอร์ระบบ สถาปัตยกรรมตัวควบคุม ฟังก์ชันความสูญเสีย หรือค่าตั้งการประเมินอย่างชัดเจน
- [ ] อธิบายความแตกต่างของค่าตัวเลขและรูป
- [ ] ไม่กล่าวว่าการตรวจบนจุดตัวอย่างเป็นการพิสูจน์อย่างเป็นทางการ
- [ ] เก็บและอธิบายกรณีล้มเหลวกับข้อจำกัด

## คำสั่งตรวจสอบภายในเครื่อง

```bash
git diff --check
make checks
make quality-gate
```

รวมโค้ดผ่านบรานช์ `main` ที่ได้รับการป้องกันเท่านั้น และทำเมื่อคอมมิตล่าสุดผ่านการตรวจที่บังคับทั้งหมดแล้ว
