# การทำซ้ำผล

## ทำซ้ำชุดตรวจ

```bash
python -m pip install -e .
make checks
make quality-gate
```

## ทำซ้ำการทดลอง

สำรองผลลัพธ์ที่ Git ติดตามอยู่ก่อน แล้วจึงรัน:

```bash
python scripts/run_full_experiment.py
```

โค้ดกำหนดค่าเมล็ดสุ่มของ Python, NumPy และ PyTorch ไว้แล้ว ควรบันทึกคอมมิต เวอร์ชัน Python เวอร์ชันแพ็กเกจที่ใช้ และค่าตั้งของการทดลองไว้กับผลลัพธ์ทุกชุด

## ความต่างที่คาดได้

ระบบปฏิบัติการหรือเวอร์ชันไลบรารีที่ต่างกันอาจทำให้ค่าตัวเลขหรือการเข้ารหัส PNG ต่างกันเล็กน้อย ก่อนยอมรับการเปลี่ยนแปลง ให้เปรียบเทียบตัวชี้วัดเชิงตัวเลขและตรวจว่าพิกเซลของรูปมีเนื้อหาเหมือนเดิม

## ขอบเขต

การทำซ้ำผลหมายถึงขั้นตอนที่บันทึกไว้สามารถสร้างหลักฐานที่เทียบเคียงกันได้ ไม่ได้ทำให้การตรวจ Lyapunov บนจุดตัวอย่างหรือการประเมินบริเวณดึงดูดกลายเป็นการพิสูจน์เสถียรภาพอย่างเป็นทางการ
