# การทำซ้ำผล

## ทำซ้ำชุดตรวจ

```bash
python -m pip install -e ".[dev]"
make checks
make quality-gate
```

## ทำซ้ำการทดลอง

สำรองผลลัพธ์ที่ Git ติดตามอยู่ก่อน แล้วจึงรัน:

```bash
python scripts/run_full_experiment.py
```

โค้ดกำหนดค่าเมล็ดสุ่มของ Python, NumPy, PyTorch และอุปกรณ์ CUDA ที่มีไว้แล้ว ควรบันทึกคอมมิต เวอร์ชัน Python เวอร์ชันแพ็กเกจที่ใช้ อุปกรณ์ และค่าตั้งของการทดลองไว้กับผลลัพธ์ทุกชุด

## ความต่างที่คาดได้

ระบบ อุปกรณ์ หรือเวอร์ชันไลบรารีที่ต่างกันอาจทำให้ค่าตัวเลขหรือการเข้ารหัส PNG ต่างกันเล็กน้อย เมล็ดสุ่มที่คงที่ไม่ได้รับประกันความเหมือนกันทุกบิตใน CPU, GPU, การใช้งาน BLAS หรือรุ่น dependencies ทุกแบบ ก่อนยอมรับการเปลี่ยนแปลง ให้เปรียบเทียบตัวชี้วัดเชิงตัวเลขและตรวจว่าพิกเซลของรูปมีเนื้อหาเหมือนเดิม

## ขอบเขต

การทำซ้ำผลหมายถึงขั้นตอนที่บันทึกไว้สามารถสร้างหลักฐานที่เทียบเคียงกันได้ ไม่ได้ทำให้การตรวจ Lyapunov บนจุดตัวอย่างหรือการประเมินบริเวณดึงดูดกลายเป็นการพิสูจน์เสถียรภาพอย่างเป็นทางการ
