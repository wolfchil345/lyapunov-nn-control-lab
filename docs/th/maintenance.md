# การบำรุงรักษา

## รายการประจำ

- ดึง `main` ล่าสุดและตรวจอัปเดตแพ็กเกจที่เปิดอยู่
- รัน `python scripts/project_status.py` และ `make quality-gate`
- ยืนยันป้ายเวิร์กโฟลว์และดัชนีเอกสารทั้งสี่ภาษา
- ตรวจผลลัพธ์ที่ Git ติดตามเพื่อหาการสร้างใหม่โดยไม่ตั้งใจ
- วางการทดสอบไว้ใกล้กับพฤติกรรมใหม่ และอัปเดตเอกสารทั้งสี่ภาษา

## หลังเพิ่มไฟล์ใหม่

- เพิ่มไฟล์สำคัญลงใน `KEY_FILES` เมื่อเหมาะสม
- เชื่อมโยงเอกสารสำหรับผู้ใช้จากดัชนีของทุกภาษา
- เพิ่มการทดสอบเมื่อสคริปต์หรือตัวตรวจได้รับพฤติกรรมใหม่

## ก่อนการสาธิตหรือการเผยแพร่

ใช้สาขาที่สะอาด ยืนยันสถานะ Git ตรวจคอมมิตล่าสุด ทบทวนข้อจำกัด และตรวจว่าผลที่แสดงตรงกับโค้ดและบันทึกการเผยแพร่ปัจจุบัน

ห้ามลบแท็กเก่าหรือบังคับอัปเดตรุ่นที่เผยแพร่แล้ว
