# ข้อจำกัด

## แบบจำลองและข้อมูล

- ระบบเป็นแบบจำลองมวล-สปริง-แดมเปอร์เชิงเส้น
- สถานะสำหรับฝึกครอบคลุมบริเวณจำกัดและใช้ LQR เป็นตัวควบคุมครู
- ผลลัพธ์ไม่ยืนยันความสามารถในการใช้ทั่วไปกับระบบไม่เชิงเส้นหรือสถานะที่ไม่เคยพบ

## หลักฐานด้านเสถียรภาพ

- ฟังก์ชัน Lyapunov แบบกำลังสองสืบทอดจากการออกแบบ LQR ค่านาม
- การประเมิน `V_dot` และบริเวณดึงดูดใช้กริด เกณฑ์ และช่วงเวลาจำลองที่จำกัด
- การไม่พบจุดละเมิดในตัวอย่างไม่ถือเป็นการพิสูจน์เชิงรูปแบบหรือทั่วทั้งปริภูมิ

## หลักฐานด้านความทนทาน

- ขีดจำกัดแอกชูเอเตอร์ ระดับสัญญาณรบกวน และความแปรผันของพารามิเตอร์เป็นกรณีที่เลือก ไม่ใช่ชุดความไม่แน่นอนที่ครบถ้วน
- ตัวแก้เชิงตัวเลขและเวอร์ชันแพ็กเกจอาจทำให้เกิดความแตกต่างเล็กน้อย
- ไม่มีการทดสอบกับฮาร์ดแวร์ ความหน่วง การควอนไทซ์ ความผิดพลาด หรือการโจมตี

## การใช้อย่างรับผิดชอบ

รีโพซิทอรีนี้เป็นซอฟต์แวร์วิจัยเพื่อการศึกษา ไม่ใช่ตัวควบคุมที่ได้รับการรับรองความปลอดภัย ต้องตรวจสอบอิสระก่อนนำวิธีไปใช้กับอุปกรณ์จริง

งานในอนาคตครอบคลุมระบบไม่เชิงเส้น การพิสูจน์เชิงรูปแบบ ฟังก์ชัน Lyapunov ที่เรียนรู้ได้ การวิเคราะห์ความไม่แน่นอนที่กว้างขึ้น และการตรวจสอบด้วยฮาร์ดแวร์
