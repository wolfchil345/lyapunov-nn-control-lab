# プルリクエストのレビュー

## 一般レビュー

- [ ] タイトルと概要が、範囲を限定した一つの変更を説明している。
- [ ] テストと必須チェックが合格する。
- [ ] ユーザーから見える動作が変わる場合は、ドキュメントを4言語すべてで更新する。
- [ ] 生成ファイルを追跡するか無視するかを意図的に決める。
- [ ] マージ前に未解決の会話を解消する。

## 科学的レビュー

- [ ] 乱数シード、プラントパラメータ、制御器構成、損失関数、評価設定の変更が明記されている。
- [ ] 数値と図の差分を説明する。
- [ ] サンプル点での確認を形式的証明として示さない。
- [ ] 失敗例と制約を残す。

## ローカルで実行するコマンド

```bash
git diff --check
make checks
make quality-gate
```

最新のコミットが必須チェックをすべて通過した後、保護された `main` ブランチ経由でのみマージします。
