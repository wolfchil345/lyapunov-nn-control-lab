# 方法論

このドキュメントでは、Lyapunov neural-network control lab で使用する主要な制御工学の考え方を説明します。

## 座標規約

本リポジトリは、正規化された無次元の 2 次モデルを使用します。正規化時間は `tau`、正規化位置座標は `q`、正規化速度は `v = dq/dtau`、正規化制御入力は `u`、状態は `x = [q, v]` です。したがって `||x||_2 = sqrt(q^2 + v^2)` と `||x||_2^2 = q^2 + v^2` は、SI 単位の位置と速度を混ぜた値ではなく、正規化状態座標における Euclidean ノルムです。

## 1. 質量ばねダンパ系

このプロジェクトは 2 次の質量ばねダンパ系を対象とします。

```text
x = [q, v]
```

システムは状態空間形式で表されます。

```text
dx/dtau = A x + B u
```

ここで x は状態、u は制御入力、A はプラント動特性、B は入力がプラントへ与える影響を表します。

公称パラメータに対して `A` の固有値は `-0.2 + 1.4j` と `-0.2 - 1.4j` です。どちらも実部が負なので、無制御の公称線形プラントはすでに漸近安定です。LQR は過渡応答と制御トレードオフを変えるものであり、このプロジェクトは開ループ不安定な公称プラントの安定化ではなく、模倣、性能、ロバスト性、安定挙動の維持を研究します。

## 2. LQR 基準制御器

線形二次レギュレータ（LQR）を古典最適制御の基準として使用します。

```text
u = -Kx
```

`Q` と `R` は無次元の目的関数重みです。得られる積分値は物理エネルギーではなく、LQR-style の二次コストです。LQR はニューラルネットワークが模倣するための強力な参照制御器を与えます。

## 3. ニューラルネットワーク制御器

ニューラルネットワーク制御器は、正規化された `q` と `v` を入力に受け取り、1 つの正規化スカラー制御入力を出力します。

```text
NN(x) ≈ LQR(x)
```

これは模倣学習であり、ニューラルネットワークはサンプル状態上で LQR 制御器のふるまいを学習します。

## 4. Lyapunov 安定性確認

Lyapunov 関数は安定性を考察するためのエネルギー類似関数です。

```text
V(x) = x^T P x
```

閉ループダイナミクスに沿った導関数は次のとおりです。

```text
V-dot(x) = 2 x^T P (A x + B pi(x))
```

評価器は、サンプル上の 2 つの異なる条件を報告します。

```text
basic decrease: V-dot(x) <= 0
decay margin:   V-dot(x) + alpha * ||x||_2^2 <= 0
```

`alpha > 0` では 2 つ目の条件の方が強い条件です。平衡点は `V(0) = V-dot(0) = 0` なので、厳密な原点だけを除外し、その近傍全体を隠しません。既定の小さな数値許容差 `1e-9` は `alpha` とは別に浮動小数点ノイズを扱います。グリッド結果は有限サンプル領域のみを対象としており、連続状態空間に対する形式的証明ではありません。

## 5. 安定性を考慮した学習

ニューラルネットワークは、模倣損失と Lyapunov 安定性ペナルティの両方で学習します。

```text
total loss = imitation loss + stability penalty
```

`alpha = 0.05` として、学習は評価で使うのと同じ減衰残差の正の部分を最小化します。

```text
decay residual = V-dot(x) + alpha * ||x||_2^2
stability penalty = mean(ReLU(decay residual))
```

## 6. アクチュエータ飽和

このプロジェクトでは、正規化制御入力の上限制約も評価します。

```text
u = clip(u, -u_max, u_max)
```

これにより、アクチュエータ制約が閉ループ安定性と性能に与える影響を確認します。

## 7. ロバスト性実験

学習済み制御器が不完全条件下でも有効かどうかを評価します。

ノイズロバスト性実験では計測ノイズを加えます。

```text
x_measured = x + noise
```

同じスカラー Gaussian 標準偏差を、正規化座標 `q` と `v` に独立に適用します。

要求した各振幅は、同じ繰り返し seed リストで評価します。各 seed について、シミュレーションは 1 つの標準化 Gaussian 系列を生成し、各振幅でスケーリングします（common random numbers）。これにより seed ペアリング比較が可能になりますが、確率的不確実性やプラットフォーム差が完全になくなることを意味しません。

stability-weight ablation も同じペアリング原則に従い、すべての重みに対して明示的な model-initialization seeds を共通利用します。seed ごとの trial 行は、集約平均、標本標準偏差、標準誤差と分離して保持します。

parameter robustness 実験では、正規化された質量・減衰・剛性係数を変更してモデリング誤差を模擬します。

## 8. 位相平面図と Lyapunov 等高線

位相平面図は正規化位置と正規化速度を描き、軌道が原点へ向かうかを示します。

Lyapunov 等高線図は、Lyapunov 関数の等位集合上に軌道を重ねて表示します。

これらの図は閉ループ安定挙動を視覚的に説明します。

## 9. 有限時間収束解析

各サンプル初期状態 `x0` について、実験は `0 <= t <= T` で `x(t; x0)` をシミュレーションし、次の厳密基準をそのまま適用します。

```text
||x(T)||_2 < epsilon
```

評価器は、シミュレーションが成功し、時刻 `T` に到達し、時間と状態値が有限であることを要求します。失敗や非有限出力は、非収束として黙って分類せずエラーにします。

`T` は正規化時間で、`epsilon` は正規化状態の Euclidean 許容差です。結果は時間幅 `T`、許容差 `epsilon`、グリッド境界と解像度、試験数、収束数、収束率を記録します。これはサンプル有限時間収束マップです。収束が遅い状態は、`t -> infinity` で収束する場合でも時刻 `T` で失敗し得るため、失敗は数学的吸引領域の外側であることを意味しません。

原点平衡点の真の吸引領域は概念的に次です。

```text
R = {x0 : x(t; x0) -> 0 as t -> infinity}.
```

有限時間シミュレーションはこの定義を検証しません。妥当な推定には、減少が検証された不変 Lyapunov 劣位集合、適用可能な sum-of-squares 法、到達可能性・不変性解析、形式検証、または適切な線形系の解析結果などが必要です。`{x : V(x) <= c}` を描いただけでは、認証済み吸引領域にはなりません。

有限時間マップと別個のサンプル Lyapunov 確認は異なる問いに答えるものであり、どちらも連続状態吸引領域の形式証明ではありません。

## 10. Stability-weight ablation study

ablation study では、異なる Lyapunov penalty 重みで制御器を学習します。

基本導関数違反率と、より強い decay-margin 違反率を分けて報告し、final normalized-state norm、normalized settling time、quadratic LQR-style cost、integrated squared control effort と併せて評価します。後者は `integral u^2 dtau` であり、物理エネルギーではありません。

## 11. まとめ

このプロジェクトは、古典制御、ニューラルネットワーク模倣学習、Lyapunov 解析、ロバスト性試験、サンプル有限時間収束解析を組み合わせています。

主要な研究課題は次です。

```text
Can a neural-network controller imitate an LQR reference while preserving useful transient, robustness, and sampled Lyapunov behavior?
```
