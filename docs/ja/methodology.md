# 方法論

このドキュメントでは、Lyapunov NN Control Labで使用する主要な制御工学の考え方を説明します。

## 座標規約

本リポジトリは、正規化された無次元の2次モデルを使用します。`tau` は正規化時間、
`q` は正規化位置座標、`v = dq/dtau` は正規化速度、`u` は正規化制御入力であり、
状態は `x = [q, v]` です。したがって `||x||_2 = sqrt(q^2 + v^2)` と
`||x||_2^2 = q^2 + v^2` は、SI単位の異なる量を混ぜたものではなく、
正規化状態座標上のEuclideanノルムです。

## 1. 質量ばねダンパ系

このプロジェクトでは、2次の質量ばねダンパ系を対象とします。

```text
x = [q, v]
```

システムは状態空間形式で表されます。

```text
dx/dtau = A x + B u
```

ここで、xは状態、uは制御入力、Aは制御対象の動特性、Bは入力が制御対象へ与える影響を表します。

公称パラメータにおける `A` の固有値は `-0.2 + 1.4j` と
`-0.2 - 1.4j` です。どちらも実部が負であるため、無制御の公称線形系は
すでに漸近安定です。LQRは開ループ不安定系を安定化するのではなく、過渡応答と
制御上のトレードオフを変えます。本プロジェクトでは模倣、性能、ロバスト性、
および安定挙動の維持を検討します。

## 2. LQR基準制御器

線形二次レギュレータを、古典的な最適制御の基準として使用します。

```text
u = -Kx
```

`Q` と `R` は正規化された目的関数の重みであり、二次コストは物理エネルギーでは
ありません。LQRは、ニューラルネットワークが模倣するための強力な基準制御器です。

## 3. ニューラルネットワーク制御器

ニューラルネットワーク制御器は、位置と速度を入力として受け取り、1つのスカラー制御入力を出力します。

```text
NN(x) ≈ LQR(x)
```

これは模倣学習であり、ニューラルネットワークはサンプリングされた状態上でLQR制御器のふるまいを学習します。

## 4. Lyapunov安定性確認

Lyapunov関数は、安定性を考察するために使用されるエネルギーのような関数です。

```text
V(x) = x^T P x
```

閉ループダイナミクスに沿った時間微分は次のとおりです。

```text
V-dot(x) = 2 x^T P (A x + B pi(x))
```

評価器は、サンプリング点における二つの異なる条件を報告します。

```text
基本減少条件:     V-dot(x) <= 0
減衰マージン条件: V-dot(x) + alpha * ||x||_2^2 <= 0
```

`alpha > 0` の場合、二つ目の条件の方が強い条件です。平衡点では
`V(0) = V-dot(0) = 0` となるため、厳密な原点だけを評価から除外し、
その周囲の領域は除外しません。既定の数値許容誤差 `1e-9` は浮動小数点誤差のための値であり、
`alpha` とは別です。グリッド評価は有限個のサンプルに基づく経験的な結果であり、
連続状態空間全体に対する形式的な安定性証明ではありません。

## 5. 安定性を考慮した学習

ニューラルネットワークは、模倣損失とLyapunov安定性ペナルティの両方を用いて学習します。

```text
総損失 = 模倣損失 + 安定性ペナルティ
```

学習では `alpha = 0.05` を使用し、評価と同じ減衰残差の正の部分を最小化します。

```text
減衰残差 = V-dot(x) + alpha * ||x||_2^2
安定性ペナルティ = mean(ReLU(減衰残差))
```

## 6. アクチュエータ飽和

正規化制御入力の上限を表す飽和制御も評価します。

```text
u = clip(u, -u_max, u_max)
```

これにより、アクチュエータの制限が閉ループ安定性と制御性能に与える影響を確認します。

## 7. ロバスト性実験

学習した制御器が、不完全な条件でも有効に機能するかを評価します。

ノイズロバスト性実験では、計測値にノイズを加えます。

```text
x_measured = x + noise
```

同じスカラーGaussian標準偏差を、正規化された `q` と `v` に独立に適用します。

パラメータロバスト性実験では、正規化質量・減衰・剛性係数を変更し、モデル化誤差を再現します。

## 8. 位相平面図とLyapunov等高線

位相平面図では、位置と速度をプロットし、軌道が原点へ向かうかを確認します。

Lyapunov等高線図では、Lyapunov関数の等位集合上に軌道を重ねて表示します。

これらの図により、閉ループ系の安定挙動を視覚的に説明できます。

## 9. 有限時間収束解析

各サンプル初期状態 `x0` について、`0 <= t <= T` の範囲で
`x(t; x0)` をシミュレーションし、次の厳密な判定だけを適用します。

```text
||x(T)||_2 < epsilon
```

評価器は、シミュレーションが成功して時刻 `T` に到達し、時間と状態の値が
有限であることを要求します。失敗または非有限の結果は、非収束として黙って
分類せずエラーにします。

`T` は正規化時間、`epsilon` は正規化状態のEuclidean許容値です。
結果には時間幅 `T`、許容値 `epsilon`、グリッド範囲と解像度、試験数、
収束数、収束率を記録します。これはサンプル有限時間収束マップです。
収束が遅い状態は、`t -> infinity` で収束する場合でも時刻 `T` の判定に
失敗し得るため、この失敗は数学的な吸引領域の外側であることを意味しません。

原点平衡点に対する真の吸引領域は、概念的には次の集合です。

```text
R = {x0 : x(t; x0) -> 0 as t -> infinity}.
```

有限時間シミュレーションではこの定義を検証できません。妥当な推定には、
減少条件を検証した不変Lyapunov劣位集合、適用可能なsum-of-squares法、
到達可能性・不変性解析、形式検証、または適切な線形系に対する解析結果などが
必要です。`{x : V(x) <= c}` を描画しただけでは、認証された吸引領域には
なりません。有限時間収束マップと別個のサンプルLyapunov評価は異なる問いに
答えるもので、どちらも連続状態空間の形式的な吸引領域証明ではありません。

## 10. 安定性重みのアブレーション研究

アブレーション研究では、異なるLyapunovペナルティ重みを使用して複数の制御器を学習します。

基本微分条件の違反率と、より強い減衰マージン条件の違反率を別々に報告し、
正規化最終状態ノルム、正規化整定時間、LQR型二次コスト、制御入力二乗積分と
併せて評価します。制御入力二乗積分は物理エネルギーではありません。

## 11. まとめ

このプロジェクトは、古典制御、ニューラルネットワークによる模倣学習、
Lyapunov解析、ロバスト性試験、サンプル有限時間収束解析を組み合わせています。

主要な研究課題は次のとおりです。

```text
ニューラルネットワーク制御器はLQR基準を模倣し、有用な過渡応答、ロバスト性、サンプルLyapunov挙動を維持できるか？
```
