# 多言語化ガイド

## 対応言語

Viewer-facing documentationは英語 (`en`)、日本語 (`ja`)、韓国語 (`ko`)、タイ語 (`th`) で保守します。全ての `docs/en/*.md` pageは他の3言語folderに同じfilenameを持ち、1行目にlanguage switcherを置きます。

## 翻訳するもの

- README、documentation、community policy、release note、contribution template。
- Heading、説明、caption、warning、user instruction。
- Localized report generatorで生成するexperiment-report prose。

## 英語のまま保つもの

Code identifier、function/class name、filename、path、configuration key、API name、workflow syntax、CLI command、数学記号、CSV column name。

## 科学的asset

言語間で数値証拠を同一にするため、plotとCSV dataは一つのcanonical setを維持します。Plot labelは英語のままにし、localized READMEとfigure guideが翻訳captionと解釈を提供します。

## Compatibility page

旧 `docs/*.md` URLは4つのlocalized counterpartへ案内する多言語language-choice pageです。新しいlinkは `docs/<language>/<filename>.md` を直接targetにします。

## 検証

`python scripts/check_docs_links.py` は全Markdown fileとlocal image targetを確認します。Multilingual testはfile-family parityとlanguage switcherを検証します。
