# 制約

## モデルとデータ

- プラントはシミュレーション上の線形質量ばねダンパ系です。
- 学習状態は有界領域を対象とし、LQR制御器を教師として使います。
- 非線形プラントや未観測状態への一般化性能は示していません。

## 安定性の証拠

- 二次形式の Lyapunov 関数は公称LQR設計から得ています。
- `V_dot` と引き込み領域の評価には、有限グリッド、閾値、シミュレーション評価時間を使用します。
- サンプル点で違反が0であっても、形式的または大域的な証明にはなりません。

## ロバスト性の証拠

- アクチュエータ制限、ノイズレベル、パラメータ変動は選択したシナリオであり、網羅的な不確かさの集合ではありません。
- 数値ソルバや依存関係のバージョンにより、小さな差が生じる場合があります。
- ハードウェア、遅延、量子化、故障、敵対的入力のテストは含みません。

## 責任ある利用

このリポジトリは教育研究ソフトウェアであり、安全認証済み制御器ではありません。物理装置へ適用する前に独立検証してください。

今後は、非線形プラント、形式的検証、学習したLyapunov関数、より広い不確かさ解析、実機検証を検討します。
