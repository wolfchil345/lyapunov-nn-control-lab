# 発表・口頭試問の質問

## 動機と設計

**なぜLQRを使うか?** 透明性のある安定化ベースラインであり、線形公称プラントに対する信頼できる模倣目標を与えるためです。

**ネットワークは何を学ぶか?** 位置と速度からスカラーの制御力への対応付けです。

**なぜ `u(0) = 0` を強制するか?** 目標状態でゼロでない制御入力があると、意図した平衡点を崩す可能性があるためです。

## 安定性

**グリッド確認は大域的安定性を証明するか?** いいえ。一つのLyapunov候補関数を用いて、有限個のサンプル状態だけを評価します。

**なぜLyapunovペナルティを使うか?** 模倣誤差だけでは閉ループ系の減衰を直接測れません。ペナルティは、学習中のサンプル点で減少条件を満たすよう促します。

## 評価

**最も重要な指標は何か?** 一つには決められません。収束性、コスト、入力の大きさ、サンプル点での安定性、ロバスト性を組み合わせて解釈します。

**なぜ飽和、ノイズ、パラメータ変動を試すか?** 実際の制御系には入力制限、センサー誤差、モデルの不一致があるためです。

## 制約と次の研究

プラントは単純で、証拠はすべてシミュレーションに基づき、学習領域外の挙動は不確かです。非線形プラント、形式的検証、実機実験、KANなどの別構成が今後の強化案です。
